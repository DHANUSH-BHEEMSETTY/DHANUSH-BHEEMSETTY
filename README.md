## 📂 Featured Projects

### 🚀 Smart Resume Screener
> Automated, explainable candidate ranking using structured LLM outputs.

* **The Problem:** Manual screening is slow, subjective, and inconsistent.
* **The Solution:** A full-stack pipeline that extracts structured candidate data from PDFs using Google Gemini 1.5 Flash. It calculates deterministic match scores (preventing LLM hallucinations) and serves explainable results via a React dashboard.
* **Tech Stack:** React • Node.js • TypeScript • Gemini API • Zod
* **Highlights:** Strict schema validation, deterministic scoring, Explainable AI.
* **Why It's Impressive:** Demonstrates advanced AI engineering by handling unstructured data and enforcing strict output schemas.

<br>

### 🚀 Smart Building Safety Monitoring
> Real-time computer vision dashboard for hazard detection and dynamic evacuation.

* **The Problem:** Current safety systems operate in silos; fire alarms don't calculate safe evacuation paths.
* **The Solution:** Processes live video feeds using YOLOv8 to detect fire/smoke. Upon detection, it uses A* and Dijkstra pathfinding via NetworkX to dynamically calculate the safest evacuation route on a floor plan.
* **Tech Stack:** Python • FastAPI • Streamlit • YOLOv8 • OpenCV • NetworkX
* **Highlights:** Real-time CV inference, dynamic graph pathfinding, low-latency streaming.
* **Why It's Impressive:** Bridges AI and traditional algorithms, running heavy machine learning concurrently with graph pathfinding.

<br>

### 🚀 Real-Time Restricted Area Monitoring
> Ultra-low latency object detection and cloud logging pipeline.

* **The Problem:** Physical security lacks real-time, globally accessible cloud alerting without constant refreshing.
* **The Solution:** Local Python clients run heavy YOLO inference on webcams and push structured logs to a Supabase database. A FastAPI dashboard consumes this via WebSockets for instant, live-streaming monitoring.
* **Tech Stack:** FastAPI • Streamlit • Supabase (PostgreSQL) • YOLO • WebSockets
* **Highlights:** Edge AI inference, real-time WebSocket streaming, event-driven architecture.
* **Why It's Impressive:** Highlights strong systems engineering by separating heavy local AI from lightweight, real-time cloud distribution.

<br>
